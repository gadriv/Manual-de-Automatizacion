3 Inteligencia (Proxy Multimodelo)

LiteLLM traduce cualquier modelo al formato OpenAI/Anthropic.

Venv & LiteLLM 
mkdir -p ~/Desktop/Proyectos/[mi-proyecto] 
&& cd $_
python3.13 -m venv venv
source venv/bin/activate
pip install 'litellm[proxy]'

export GEMINI_API_KEY="TU_LLAVE_AI_STUDIO"
litellm --model gemini/gemini-1.5-pro --port 4000

4 GitHub Bootstrapping

Git Initializer 
export PROJECT_NAME="nombre-del-proyecto"
mkdir $PROJECT_NAME && cd $PROJECT_NAME

git init
echo "# $PROJECT_NAME" > README.md
echo "venv/" > .gitignore
echo "__pycache__/" >> .gitignore

git add .
git commit -m "Initial commit: Estructura base"
gh repo create $PROJECT_NAME --private --source=. --remote=origin --push

5 Claude Code

Configuración de Alias 
sudo chown -R $(whoami) 
/usr/local/lib/node_modules
npm install -g @anthropic-ai/claude-code

# Agregar a ~/.zshrc
alias wolf-ia='export ANTHROPIC_BASE_URL="http://0.0.0.0:4000" && claude'
